# 4. HERO ANIMATION — VERY IMPORTANT

The hero should contain a **3D/animated martial artist character**.

The character should look like a realistic athletic martial artist, NOT a cartoon.

The character can be:

* Wearing a modern martial arts training outfit
* In a fighting stance
* Athletic and dynamic
* Slightly stylized but realistic

The most important interaction:

When the user scrolls vertically down the page, the character should perform a **roundhouse kick**.

The kick should be synchronized with scrolling.

For example:

At the beginning:
Character is standing in fighting stance.

As the user scrolls:

1. Character prepares
2. Body rotates
3. Leg rises
4. Roundhouse kick extends
5. The kick visually hits / passes through a floating information card
6. The card moves away / breaks apart / transitions into the next section
7. The character returns to stance or transitions out

The effect should feel like the martial artist is physically interacting with the website.

Do NOT make the animation random.

It should be tied to scroll progress.

Use smooth scroll-based animation with technologies such as:

* GSAP + ScrollTrigger
* Three.js
* React Three Fiber if using React
* CSS 3D transforms where appropriate

If a fully realistic 3D character cannot be implemented without external assets, create a visually convincing alternative using a high-quality 3D/stylized martial artist model or layered silhouette animation.
